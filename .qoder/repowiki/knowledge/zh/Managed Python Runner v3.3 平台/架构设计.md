顶层 pyproject.toml 通过 setuptools.packages.find 将 runner_engine、build_service、operator_authoring、publish_service 四个包纳入同一发行物，并暴露 mpr-runner / mpr-build-service / mpr-publish-service / mpr-agent / mpr-publish 五个 CLI 入口，分别对应运行时代码执行、依赖镜像构建、算子发布、Worker Agent 与 Operator Authoring 五个子模块。
- 运行时边界：runner_engine 作为 gRPC 进程承载租户隔离的 Python 代码执行；nifi_integration 在 NiFi 侧通过 Controller Service 调用远端 runner_engine。
- 构建/发布链路：operator_authoring 扫描源码产出 ExecutionPlan，publish_service 基于该计划编译 Runner/NiFi Native 双后端并发布到 MinIO，build_service 将 requirements 锁定为 Docker 镜像供 runner_engine 拉取。
- Web 层（web）聚合 publish_service BFF、observe 与管理面板，作为 ASGI 单进程对外暴露 HTTP API。
- 共享基础设施：PostgreSQL（psycopg[binary]+psycopg-pool）用于持久化镜像元数据与发布工件，MinIO 用于对象存储，gRPC 是 runner_engine 与 nifi_integration 之间的协议契约。

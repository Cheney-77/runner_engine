通过环境变量注入配置：`BUILD_DATABASE_URL`（必填）、`BUILD_RUNNER_BASE_IMAGE`（必填，需为 `repo@sha256:<digest>` 形式）、`BUILD_REGISTRY_REPO`（必填）、`BUILD_PYTHON_VERSION`、`BUILD_PLATFORM`、`BUILD_UV_PYTHON_PLATFORM`、`BUILD_POLICY_VERSION`、`UV_DEFAULT_INDEX`、`BUILD_ALLOW_SUPERSET_REUSE`、`BUILD_LOG_LEVEL`、`BUILD_ADMIN_TOKEN`；CLI 启动方式为 `python -m build_service`，支持 `--listen-host/--listen-port/--log-level` 参数。

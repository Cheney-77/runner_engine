- 所有数据库访问通过 `with self.pool.connection() as conn:` 上下文管理器包裹，并在方法内直接执行 SQL，避免额外的事务封装。
- 幂等写入统一采用 `INSERT ... ON CONFLICT (...) DO NOTHING RETURNING *` 模式，由调用方根据返回值判断是新建还是已存在。
- 对外暴露的状态机字段（status、resolution_kind、lifecycle_state）均使用 CHECK 约束限制枚举取值，而非仅在 Python 层校验。
- 错误消息在落库前统一截断至 8192 字节（`message[-8192:]`），防止长异常文本撑大 last_error/error_message 列。
- 可变配置以 frozen dataclass 承载（`BuildSettings`、`RuntimeBuildSpec`），不可变且可哈希，便于作为缓存键与 spec 标识。
- 扩展行为通过继承基类并重写关键方法实现（如 `LifecycleBuildStore` 继承 `BuildStore` 覆盖 `_init_schema/get_for_request/find_smallest_superset/bind_request/claim_build`），保持核心语义不变。

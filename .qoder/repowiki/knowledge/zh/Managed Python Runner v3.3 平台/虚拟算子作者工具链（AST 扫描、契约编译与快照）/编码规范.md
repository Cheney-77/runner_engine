- 所有外部可见的数据结构统一以 Pydantic BaseModel 定义，并在 field_validator / model_validator 中完成格式与业务约束校验（如 operator name 白名单、python_path POSIX 相对路径、binding 源与字段的互斥依赖）。
- 枚举型常量采用 enum.StrEnum（CallableKind、BindingSource、Codec、NonePolicy、OutputValueSource），序列化时直接取 .value 字符串。
- 错误语义通过自定义异常表达：`ContractCompilationError(ValueError)` 表示契约编译期失败，`SnapshotError(ValueError)` 表示快照阶段失败，均继承自 ValueError。
- 源码遍历统一遵循安全策略：跳过 `EXCLUDED_DIRS`、拒绝符号链接、对语法错误记录 `CatalogWarning(severity='error')` 而非抛出异常，由上层 `compile_virtual_contract` 汇总阻断。
- 可调用项排序与优先级通过 `score` 字段实现：名称权重表 `NAME_WEIGHTS` 配合 `_callable_score` 给常见入口（run/process/predict 等）及 `operator` 装饰器加分，最终按 `(-score, id)` 排序。
- 版本与可复现性通过双摘要保证：`COMPILER_VERSION = 'virtual-direct-v1'` 标记编译器协议，`source_revision` 对全量文件内容与路径做确定性 SHA256，`contract_sha256` 对契约 JSON 做规范化哈希。

模块按职责划分为四个层次，依赖方向单向自上而下：
- 数据模型层 `model.py`：基于 Pydantic BaseModel 定义所有不可变数据结构（`ProjectCatalog`、`CallableInfo`、`ClassInfo`、`ParameterInfo`、`VirtualOperatorContract`、`ArgumentBinding`、`OutputSpec` 等），并通过 `StrEnum` 声明 `CallableKind`、`BindingSource`、`Codec`、`NonePolicy`、`OutputValueSource` 等枚举；所有字段校验集中在 `field_validator` / `model_validator`。
- 源码扫描层 `ast_scanner.py`：使用标准库 `ast` 遍历 `.py` 文件，忽略 `EXCLUDED_DIRS`、`test_` 前缀和符号链接，解析函数/类/方法签名并计算 `score`（含 `operator`/`dsc.operator` 装饰器加分），输出 `ProjectCatalog`；同时通过 `source_revision()` 对全量文件内容做确定性 SHA256 摘要。
- 推理与建议层 `inference.py`：根据参数名与类型注解推断默认 `codec` 与绑定建议（`input.payload` / `input.metadata` / `operator.parameter`），供上层 UI 或自动补全消费。
- 编译与快照层 `compiler.py` + `snapshot.py`：`compile_virtual_contract()` 将 `VirtualOperatorContract` 与 `ProjectCatalog` 对齐校验（revision、python_path、callable_id、参数绑定合法性、async/unsupported parameter kind 等），输出 `ExecutionPlan`（含 `contract_sha256`）；`snapshot_workspace()` 复制工作区到目标目录，强制要求根目录存在 `requirements.txt`，限制大小上限并拒绝符号链接。
入口仅暴露于 `__init__.py`：`scan_project`、`compile_virtual_contract`、`ProjectCatalog`、`VirtualOperatorContract`、`ExecutionPlan`。

- 所有 Pydantic 请求模型继承自 `ApiModel`，并通过 `_to_camel` alias_generator 将 snake_case 字段自动映射到 camelCase JSON 字段。
- 工作区路径在入口处统一经 `_workspace()` 校验：拒绝空值、绝对路径、逃逸 `PUBLISH_WORKSPACE_ROOT` 的路径，并检查目标目录存在。
- 后端扩展点采用 `backends/<name>.py` 独立文件 + `backends/base.py` 中 `backend_contract_sha256` / `backend_variant_key` 计算变体标识的模式，新增后端只需实现对应 compile/publish 函数。
- HTTP 异常处理在路由层统一捕获 `PublishError`/`ValueError` 并转为 400/404/409 `HTTPException`，内部错误通过 `logger.exception` 记录后再抛出。
- 可插拔组件（store、source_store、build_client、edge_resolver）在 `PublishService.__init__` 中以默认工厂构造但允许注入，便于测试替换。
- 管理员路由通过 `lifecycle_routes._require_admin` 使用 `hmac.compare_digest` 对 Bearer token 进行常量时间比较校验，未配置时返回 503。

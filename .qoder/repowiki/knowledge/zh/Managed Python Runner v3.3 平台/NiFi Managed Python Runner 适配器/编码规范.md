- 所有 NiFi 配置项通过 `PropertyDescriptor.Builder()` 静态字段声明，并使用 `StandardValidators.NON_EMPTY_VALIDATOR` / `POSITIVE_INTEGER_VALIDATOR` 等标准校验器。
- gRPC 请求通过 `XxxRequest.newBuilder()...build()` 构造，响应通过 `response.getXxx()` 取值后映射到 `LeaseSession` / `InvocationResult` record。
- 远程错误以 `StatusRuntimeException` 抛出，`invoke` 中统一包装为 `ProcessException`，由 NiFi 回滚会话并复用同一 FlowFile UUID 以实现幂等。
- 幂等键由 processor id、release id 与 FlowFile uuid 经 SHA-256 拼接生成，`invocation_id` 使用 `UUID.randomUUID()` 保证物理重试唯一。

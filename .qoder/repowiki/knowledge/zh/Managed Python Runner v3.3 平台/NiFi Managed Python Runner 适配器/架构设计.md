模块由 Maven 多模块聚合（`nifi/pom.xml`）构成：
- `managed-python-processors/`：Java 源码层，定义 `ManagedPythonRuntimeService` 接口（含 `LeaseSession` / `InvocationResult` record），并由 `GrpcManagedPythonRuntimeService` 基于 gRPC Netty 客户端实现；`ManagedPythonTransform` 作为 NiFi `AbstractProcessor` 暴露给用户。
- `managed-python-nar/`：打包 NAR 的 Maven 子模块。
- `proto/runner.proto`：gRPC 契约，包名 `dsc.runner.v33`，生成 Java 类到 `com.dsc.nifi.proto`，被 gRPC 客户端直接消费。

依赖方向单向：`ManagedPythonTransform` → `ManagedPythonRuntimeService` 接口 → `GrpcManagedPythonRuntimeService` → `com.dsc.nifi.proto.ManagedPythonRunnerGrpc` → 远端 Runner Gateway。Controller Service 持有单例 `ManagedChannel` 与 `BlockingStub`，通过 `@OnEnabled/@OnDisabled` 生命周期管理 SSLContext 与连接；Processor 在 `@OnScheduled` 获取租约、`@OnStopped` 释放，并在每次 `onTrigger` 前调用 `ensureLease` 续租或重新获取。

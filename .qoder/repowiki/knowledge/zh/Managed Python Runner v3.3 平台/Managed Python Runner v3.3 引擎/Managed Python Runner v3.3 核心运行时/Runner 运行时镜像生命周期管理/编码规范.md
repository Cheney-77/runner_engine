- 对运行时状态的读写统一通过 `RuntimeLifecycleStore` 的 SQL 方法完成，禁止在控制器或服务层直接拼接 SQL 访问 `runner.runtime_image_lifecycle` 表。
- 所有可能进入 RETIRING/RETIRED 路径的入口（lease acquire、lease renew、invoke、worker acquire）都先查 `lifecycle.get_by_runtime_id` 再抛出 `RunnerError`，并以 `retryable=state == 'RETIRING'` 区分可重试与不可重试。
- 对共享可变状态（`WorkerPool._idle`、`_acquiring`、`service._active`）的访问一律包裹对应锁（`_lock`、`_lifecycle_gate_lock`、`_active_lock`），并在 snapshot 类方法中复制快照后释放锁。
- `begin_retirement` 使用 INSERT ... ON CONFLICT DO UPDATE 配合 CASE WHEN state = 'RETIRED' THEN 'RETIRED' ELSE 'RETIRING' END 保证幂等且不允许从 RETIRED 回退到 RETIRING。

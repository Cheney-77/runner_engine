- 所有可配置项通过 argparse + os.environ.get("RUNNER_*") 双源读取，CLI 参数优先于环境变量。
- 对外错误统一使用 errors.RunnerError(code, message, retryable=...) 抛出，由 service 层捕获后映射为 gRPC 响应。
- 跨进程边界（Operator 调用）通过 worker.http_api 的 JSON-RPC 协议传递 RunRequest/RunResult，而非直接函数调用。
- 租户隔离以 tenant_id/project_id/release_id 三元组贯穿 lease、run、worker pool 分配与 ACL 校验。

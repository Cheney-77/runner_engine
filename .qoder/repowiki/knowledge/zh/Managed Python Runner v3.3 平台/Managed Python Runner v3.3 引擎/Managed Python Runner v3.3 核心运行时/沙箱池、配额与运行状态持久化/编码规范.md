- 对外暴露的错误统一来自 `.errors` 包（`QuotaError`、`LeaseError`、`RunnerError`），并附带结构化错误码字符串与可选 `retryable` 标志。
- 所有可变共享状态（`WorkerPool._idle`、`Quota._live`/`_tenant_live`、`RunnerDB.pool`）的读写均通过显式锁（`threading.RLock` / `threading.Lock`）或 `with self.pool.connection()` 事务上下文保护。
- 数据库访问一律通过 `with self.pool.connection() as conn:` 获取连接，SQL 使用 `%s` 参数占位符，DDL 以模块级常量字符串集中声明。
- 时间比较统一使用 `time.monotonic()`（沙箱 TTL）与 `datetime.now(timezone.utc)`（持久化 TTL），并通过 `_epoch_ms` 在毫秒与 datetime 之间转换。
- 幂等性与状态机通过数据库行的 `state` 字段驱动（RUNNING/DONE/ABANDONED），更新时使用 `WHERE state = 'RUNNING'` 实现乐观状态转移，失败则抛错。

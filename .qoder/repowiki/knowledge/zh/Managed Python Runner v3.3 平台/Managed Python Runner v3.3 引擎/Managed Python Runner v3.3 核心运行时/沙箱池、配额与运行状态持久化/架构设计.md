本模块由三个相互协作但职责分离的子组件构成：
- `quota.py` 中的 `Quota` 是纯内存计数器，通过 `threading.BoundedSemaphore(max_creating)` 限制同时创建沙箱的并发数，并通过 `_live` / `_tenant_live` 维护全局与租户维度的活跃沙箱上限；`reserve_live` 在分配前检查配额并抛出 `QuotaError`，`creation_slot()` 作为上下文管理器包裹后端创建调用。
- `pool.py` 中的 `WorkerPool` 以 `(tenant_id, runtime.id, profile)` 为键对空闲 `Worker` 进行分桶缓存，`acquire` 优先复用命中桶内的存活 Worker，否则走 `quota.reserve_live` + `backend.create` 路径；`release` 根据 `policy.reuse_sandbox` 决定是否回池；`reap` / `reset_after_restart` 负责清理过期或进程重启后的孤儿沙箱，所有写操作均受 `threading.RLock` 保护，销毁时保证 `backend.destroy` 与 `quota.release_live` 恰好各执行一次。
- `state.py` 中的 `RunnerDB` 封装 `psycopg_pool.ConnectionPool`，在构造时通过 DDL 语句初始化 `runner.leases`、`runner.runs`、`runner.idempotency_keys` 三张表（含索引），并提供 Lease 生命周期管理（create/renew/delete/purge）与 Run 的 begin/finish/abandon 原子流程；幂等性通过 `FOR UPDATE` 锁住 `idempotency_keys` 行实现，`begin_run` 返回 `RunClaim` 以区分冷启动与热缓存回放；`_migrate_legacy_runs` 处理 v3.3 旧 schema 到拆分后结构的在线迁移。
依赖方向：`pool` → `quota` → `errors.QuotaError`；`state` → `errors.LeaseError`/`RunnerError`；两者互不依赖，仅通过 `model` 与 `errors` 共享类型。

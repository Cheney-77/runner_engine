- 对外 API 以类封装核心能力（`OperatorPublisher`、`Catalog`、`AccessControl`），CLI 入口通过独立的 `main()` + `if __name__ == "__main__"` 提供。
- 不可变标识符通过 SHA-256 派生：source 哈希对每个文件路径与内容做增量散列，release id 对规范化后的 identity JSON 再做一次散列。
- 持久化写入采用临时文件 + `Path.replace` 的原子替换模式，避免部分写入导致的数据损坏。
- 配置与清单序列化统一使用 `json.dumps(sort_keys=True, separators=(',', ':'))` 保证输出稳定可比较。
- gRPC 服务方法遵循 `_authorize/_authorize_lease` → 调用 `service.*` → 捕获 `RunnerError` → `_abort_runner_error` 映射到 `grpc.StatusCode` 的统一错误处理流程。

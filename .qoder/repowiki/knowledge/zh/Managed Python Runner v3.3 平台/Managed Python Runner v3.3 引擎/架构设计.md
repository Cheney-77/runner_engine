runner_engine 是单一可部署进程，由 app.main() 在启动时完成依赖注入：
- 配置层：从 --catalog/--db-url/--policies/--acl/--clusters 及 RUNNER_* 环境变量加载 Catalog、RuntimeLifecycleStore、Policy、Quota。
- 执行层：LifecycleOpenSandboxBackend → LifecycleWorkerPool（按 quota 限流、按 idle/orphan TTL 回收）→ LifecycleRunnerService（编排 Operator 发布、租约、幂等与审计）。
- 接入层：gateway.serve() 启动 gRPC 服务并挂接 AccessControl；RUNNER_ADMIN_TOKEN 非空时额外启动 RunnerAdminHTTP。
- 生命周期：service.startup/start_background/shutdown 与 lifecycle.close() 在 try/finally 中成对调用，确保后台 reaper 与 gRPC 优雅退出。
子模块通过共享 model.py 中的 Lease/RunRequest/RunResult/SecurityPolicy 等数据契约通信，不直接互相 import worker/sandbox 内部实现。

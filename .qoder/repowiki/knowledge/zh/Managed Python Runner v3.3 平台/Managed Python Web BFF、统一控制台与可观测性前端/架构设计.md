模块由四个并列的 FastAPI 子应用组成，通过 `console/main.py` 中的 `Unified` ASGI 中间件按路径分发：
- `app/`：Publish-only BFF，仅代理到 `MPR_PUBLISH_SERVICE_URL`；`gateway.PublishGateway` 是唯一的上游 HTTP 出口，使用 httpx 并区分普通/长超时；路由集中在 `main.py`，静态文件在 `static/`。
- `observe/`：独立的只读可观测性应用，提供 `/observe/*` 路由，内置 Basic Auth + CSP 安全头，通过 `database.py` / `runner_runtime.py` / `sandbox.py` 读取下游数据库与运行时信息。
- `admin/`：操作管理面，依赖 `Inventory`（只读 DB）、`AdminStore`（管理元数据 DB）、`LifecycleClient`（环境生命周期）和 `RetryClient`（构建重试），通过 `make_app()` 工厂构造 FastAPI，自带 same-origin JSON 校验与严格 CSP。
- `console/`：统一入口，`Unified.__call__` 根据 path 将请求分派给 publish/observe/admin 三个子 app，并提供 `/console/`、`/observe/`、`/admin/` 的短路径重定向。

依赖方向单向：`console` → (`app`, `observe`, `admin`)；`app` 不反向依赖其他子模块；`observe` 与 `admin` 彼此独立，仅在 `console.settings.ConsoleSettings` 中共享观察端配置。所有子应用均通过环境变量注入配置（`Settings.from_environment()` / `ConsoleSettings.environment()`），测试通过依赖注入替换 transport/store。

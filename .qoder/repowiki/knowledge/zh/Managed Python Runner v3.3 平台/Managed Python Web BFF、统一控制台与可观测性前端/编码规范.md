- 每个子应用通过 `make_app()` 工厂函数返回 FastAPI 实例，并在模块顶层调用一次以生成默认 `app`，便于测试时传入 mock 依赖。
- 外部服务地址、超时、认证等配置统一通过 `@dataclass(frozen=True)` 的 Settings 类 + `from_environment()` / `environment()` 从环境变量解析，禁止在业务代码中直接 `os.getenv`。
- 对外暴露的 URL 路径段（如 operator_id、backend、bundle_id）一律经 `segment()` 白名单校验后再拼接到上游路径，防止路径穿越。
- 对上游 Publish Service 的请求统一走 `PublishGateway.request()`，并由路由层的 `forward()` 把 httpx.TimeoutException 映射为 504、RequestError 映射为 502。
- 管理端 API 通过 middleware 强制 same-origin + `x-admin-request: 1` + `application/json` Content-Type，并对写操作记录 audit_actor 到 AdminStore。
- 所有响应统一设置安全头（X-Content-Type-Options=nosniff、X-Frame-Options=DENY、Referrer-Policy=no-referrer、CSP default-src 'self'），并在 admin/observe 子应用中显式禁用 OpenAPI docs/redoc。

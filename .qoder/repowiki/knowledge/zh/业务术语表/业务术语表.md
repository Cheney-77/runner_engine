### 算子
- 定义：指被托管的 Python 业务函数（Callable），经 operator_authoring AST 扫描后生成 virtual-direct-v1 契约，再通过 publish_service 编译为 runner 或 nifi_native 后端可执行的发布物。
- 别名：operator、Callable

### virtual contract
- 定义：算子在 Analyze 之后生成的中间契约表示，包含 constructor_bindings、argument_bindings、output 等绑定信息；创建时经可变工作区验证后再落盘为不可变快照。
- 别名：虚拟契约

### release
- 定义：一次成功编译+发布后得到的稳定产物标识（releaseId），Runner 通过 release_id 调度对应 worker 执行，NiFi 侧的幂等键也包含 release_id。
- 别名：发布版本

### lease
- 定义：Runner 端对一次算子执行资源的独占租约，含 Acquire/Renew/Release 三态，TTL 默认 15 分钟，过期由 DB 清理；NiFi 侧在调度前 acquire 并在剩余不足一分钟时续租。
- 别名：租约

### idempotency_key
- 定义：Runner 端用于崩溃恢复的幂等键，由请求内容 SHA256 与排序属性的 canonical JSON 组成；NiFi 侧则用 `SHA256(processor-id + release-id + FlowFile uuid)` 保证重试幂等。
- 别名：幂等键

### worker
- 定义：Runner 内 fork 出的用户代码执行子进程，通过自定义 MPR1 帧协议与 agent 通信，受 cgroup/prctl 隔离，输出/日志有大小上限。
- 别名：工作进程

### edge bundle
- 定义：publish_service 为 runner 后端打包的依赖与环境描述，供 BuildService 解析 requirements 并构建运行时镜像。
- 别名：边缘包

### nifi_native
- 定义：publish_service 的双后端之一，产出可直接部署到 NiFi Python extension source directory 的 artifact，发布后需单独部署（`deploymentRequired=true`）。
- 别名：原生后端

### BFF
- 定义：web/app 下纯转发的 FastAPI 前端网关，仅暴露 `/api/*` 路由到 Publish Service，自身不含业务逻辑，用于浏览器跨域与安全边界。
- 别名：前端网关、BFF 服务

### 统一控制台
- 定义：web/console 下的 FastAPI 应用，聚合 admin、observe 等子功能，作为面向运维的统一入口。
- 别名：Console

### 可观测面板
- 定义：web/observe 下的只读 FastAPI 应用，从 PostgreSQL 读取 runner 运行时指标与沙箱状态，供运维观察。
- 别名：Observe

### 生命周期治理
- 定义：runner_engine 与 build_service 共用的机制：镜像退休阻断新 acquire、孤儿沙箱 TTL 清理、admin 端点触发销毁，配合 LifecycleWorkerPool 的 acquiring 门闩防止竞态。
- 别名：lifecycle
